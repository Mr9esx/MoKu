# 成品组装刀口提示验证（2026-10-16）

## 行为

组装中的零件存在未清角的内直角时，紧凑装配信息显示“刀口待确认”。展开后按孔、槽或外轮廓分组显示，点击会选中并定位接收件，自动收起详情。黄色角标标出图纸中的具体角点，随当前零件位姿显示；隐藏零件、爆炸视图和安装播放不绘制原位角标。

采用圆柱铣刀时才存在对应加工风险。目前没有工艺和刀径依据，提示不推断刀具半径，不将风险写入真实干涉结果，也不阻断拖拽磁吸。已画圆角按实际轮廓检查；现有 Dogbone/T-bone 不重复提醒。仅检查内直角，不宣称完整可加工性验证。

重叠孔槽按实际合并边界检查。同面、同深或更深槽可移除原角点；相反/未确认加工面不作为移除依据。保留剩余材料岛的语义，避免将其凸角误报为需要清角的凹角。

## 测试与复核

- 首个缺失提示用例先失败（警告结果不存在），实现后通过。
- 独立复核发现 Points 资源未释放、重叠槽角点误报、材料岛边界误报。均增加回归用例验证失败后修复；最终独立复核的 33 项相关测试全部通过。
- `pnpm test --maxWorkers=2`：49 个文件、691 项通过。首次默认并发运行有一项既有 DXF 点数压力测试超过 5 秒；限制两 worker 后该项约 2.5 秒，全量通过，没有调整测试超时或修改导入逻辑。
- `pnpm build`：通过；保留现有主入口体积提示。
- `git diff --check`：通过。

## 浏览器验收

通过全新后台页面及公开按钮操作，没有注入应用状态：

1. “更多 → 添加组装示例”，将竖向插板 X 调整为 66。实体、目标尺寸、已声明配合和安装路径通过，仍显示 4 处刀口待确认。
2. 点击刀口提示，再点击具体槽，定位到带槽底板并收起参数详情，四个槽内角显示黄色方标。
3. 切换二维，选择底板，在“清角/T骨”中对四角应用 6 mm 狗骨。返回组装后刀口提示消失。几何改变后原加工面/配合声明按现有规则失效，提示重新确认，没有误报完全通过。
4. 撤销清角，原轮廓及确认信息恢复，4 处刀口提示重新出现。
5. 页面控制台没有错误。

效果图：`docs/design/assembly-machining-warning.png`、`docs/design/assembly-machining-relieved.png`。验收示例页保留在应用浏览器。
