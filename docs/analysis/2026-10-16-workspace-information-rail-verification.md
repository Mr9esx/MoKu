# 固定信息栏验证 · 2026-10-16

用户选择固定右侧信息栏，同时整理零件排版和成品组装。

## 实现

- 两种工作区使用相同的画布 / 信息栏网格；实际 SVG、WebGL、标题、图例与控件均在 preview-main 中，信息栏为兄弟区域。
- 桌面信息栏 304px，901–1200px 窗口为 260px；简版、选中属性和展开详情不改变宽度。手机沿用资源 / 画布 / 信息切换。
- 不超过 560px 的画布把缩放 / 视角控件抬至单独高度，避开底部工具条。组装空态保留单处引导，信息栏展示数量和检查入口。
- 视角操作说明改为可聚焦提示入口，必要检测与加工面提醒保留。
