# 2D 转 3D 组装验证

日期：2026-10-14。工作区：homemade，现有 codex/dxf-workbench 分支。保留原有未提交的清角、图纸交互及其文档/截图；本功能提交只包含组装相关文件。

## 交付行为

零件按毫米轮廓、板厚、通孔和确认加工面的浅槽构成实体。装配位置独立于二维排版与源图；完成一次拖动或参数编辑只写一条可撤销事务。增加副本保持未组装，移出组装保留库存。导入追加正确映射装配引用，二维搜索期间装配只读。

红色显示真实材料交叠的三角面，黄色显示已通过最终位置/适用配合校验的候选与落位预览，待确认候选为灰色虚线。弱磁吸保持8px且5mm进入、12px或8mm脱离，遵守轴限制且不自动旋转；Alt和工具栏均可暂停。自动吸附排除隐藏接收件、屏幕外/相机后及被真实材质遮挡的目标，槽口以加工面开口中心判断可见性。

加工面未知、失效、深度未知或计算上限会保留待确认状态。用于显示的未切槽实体不能生成确定的红色冲突或安装阻碍。未设置目标尺寸且无配合声明时明确显示“尚未设置检测依据”，仍可检查独立的几何落点。

提供XYZ位置/角度、三轴控件、平面拖动、锁定、单件隐藏、前/侧/顶视、定位、透视、爆炸查看、局部方向箭头与实际正反面高亮。面、边中点、角点参考可以预览并对齐，应用需通过相关实体/配合及目标尺寸校验；取消预览不修改存储位姿。安装顺序支持直线方向/行程和播放/滑杆预览；返回成品、Esc、爆炸、选择、撤销、提交、阻塞或模式切换都使旧播放帧失效。

## 实际浏览器验证

使用Codex内置浏览器打开本地开发工作区。以下为已执行的交互，而非仅查看代码：

1. “更多 → 添加组装示例…”追加底板与插板。初始插板X=70.4，红色材料冲突与黄色可落位槽同时可见。
2. 直接拖动插板触发磁吸，X变为66，冲突消失；一次撤销恢复70.4。最终加上遮挡过滤后，在顶视图再次拖动，仍精确吸附到66。关闭磁吸时拖动保持自由位置。
3. 目标高66改60，报告实际66与目标60±0.5，显示红色尺寸标记；撤销恢复。清空三方向目标并删除配合声明，显示“尚未设置检测依据”，没有绿色通过；四次撤销恢复全部规则。
4. 最终插板位置正确，改为从下方安装会出现独立安装阻碍。点击该问题显示实际阻碍时刻的位置和红色交叠，最终存储位姿保持不变。
5. 播放第二步后立即点击场景“返回最终装配”，后续帧没有恢复预览。另行验证播放期间Esc及爆炸查看，同样停止播放。修复过程中曾发现并修正effect重启播放的竞态。
6. 数值X=70.4，编辑为66后Esc保留70.4；Enter提交66。参考对齐预览、取消、应用与撤销均执行过；最终guard进一步禁止未验证的全局几何/尺寸预览被应用。
7. 隐藏底板后只剩插板显示，装配检查仍使用全部零件。正面高亮保留实际槽口，局部+Z箭头在遮挡中仍可见。
8. 356×846窄屏的场景与信息区域均可使用，页面scrollWidth等于356，无横向溢出。测试结束已恢复浏览器原始尺寸，保留对齐后的组装示例页。
9. 切回二维仍保留图纸和零件，返回3D保留装配；已提交修改可撤销。快捷键避开正在编辑的输入框。

## 审查

核心审查两轮修复了实际孔槽有效性、未知障碍、人工剖分接缝和共享真实边界法线。整体审查的五项问题（未知实体误报、Line释放、缺少依据、数值Esc、播放退出）已修复；最终复审补充的参考校验问题也已修复。最后一次范围复审结论：规格和质量通过，没有剩余可执行发现。审查未将未运行的浏览器操作或测试当作新证据。

## 当前范围

配合校验支持独立的直边与矩形孔槽；曲线、开放/合并/斜向等未支持配合保留待确认，不宣称通过。实体曲线沿用DXF采样精度。安装检查是保持朝向的连续直线平移，不覆盖中途旋转、材料变形、结构强度或工具可达性。

53件实际图纸的受控性能检查约6748个凸单元：实体约241ms，独立检测约25ms，候选生成约6–7秒。候选在worker执行，界面可继续操作并显示核对中；复杂模型的候选仍有等待时间。

装配沿用当前应用的页面内存保存，刷新会丢失；导出仍为二维SVG，不输出3D CAD或CNC文件。
