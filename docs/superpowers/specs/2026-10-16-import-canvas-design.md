# 导入预览画布交互

用户已确认：让画布承担浏览、选择、定位和用途确认，简化预览示例图纸弹窗。

- 顶部只保留原图 / 导入效果切换。图形数量进入底部状态，单位与空间选择放到右侧图纸设置；单位未知时设置直接展开。
- 原图画布支持拖动平移、滚轮平移、Shift 横向平移、Ctrl/⌘ + 滚轮围绕指针缩放，以及缩放按钮和适应全图。触屏可拖动，使用按钮缩放。
- 单击图形选中并联动右侧，保持视野；双击图形或点击右侧定位才放大。Shift 点选跨图层增减选择，清空最后一个图形时真正取消选择。点击空白取消选择，拖动不得误触选择。
- 选中后在画布内显示用途下拉、忽略及详细设置入口，批量操作仅影响选中图形。用途操作读取既有完整规则，只更新用途；保留槽深、槽宽和几何来源，忽略后恢复也不丢参数。详细参数继续通过右侧确认。
- 原图和导入效果共用视野控制；导入效果只读。切换视图保留各自的浏览状态，切换文件或空间时重置。不得修改原文件或提前提交工作项目。
- 沿用米白、钴蓝、朱橙视觉及现有 Select 和 tooltip。不增加依赖，不修改已有清角相关的未提交工作。

验证：新增行为测试覆盖非有限坐标、坐标翻转、视野比例和跨图层选择；执行全套测试、构建，并在浏览器验证拖动、定位、多选、用途变更及窄屏布局。
