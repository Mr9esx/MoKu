# DXF 板材工作台

用户已批准首版实现 2D DXF 导入预览与三种重排序模式，并参考 RiSu 技术栈和指定图片风格。当前工作在新建空仓库中进行，使用 codex/dxf-workbench 分支；不修改 RiSu。

React 19 + TypeScript + Vite + Zustand。米白底、深绿字、木色 12mm 零件、灰绿 5mm 零件、蓝色通孔、浅色铣槽。主区域为板材 SVG，侧栏为选中零件和优化设置；顶部导入文件、加载样例，底部零件表与检查信息。支持缩放、选择、锁定、厚度编辑、候选对比、应用、撤销及 SVG 导出。

本地浏览器解析 ASCII DXF，初期支持闭合 LWPOLYLINE / POLYLINE（含 bulge）、CIRCLE、由 LINE / ARC 构成的闭合链及 TEXT 标注。检查单位并识别真实 1220×2440 矩形板框，图层区分外切、通孔、浅槽和参考信息；未知与不支持的加工几何须明显提示，不能静默改变零件。未知厚度须用户填写。无板框、单位不明或非毫米输入须明确报错或要求确认；不执行图纸文字中的任何指令。

统一毫米坐标与独立零件轮廓，源模型保持不变，布局只改变板材、平移和旋转；这个接口预留 Three.js / React Three Fiber 后续挤出。3D 家具装配不在本次实现范围内，不设置无效的 3D 入口。

重排模式：利用率优先（先板数再布局紧凑）；加工优先（CNC 空走距离近似与布置稳定性，不冒称准确加工时间）；余料优先（最大可用矩形余料）。参数包含板边留量、零件间距、允许 90° 旋转、余料最小尺寸、计算预算。优先保持原板数；不能满足约束时返回失败说明，不能漏件或宣称优化完成。初期不支持孔内套料，也不翻面或镜像。锁定件保留坐标与所在板。计算在 Worker 中进行，可取消，保留当前最佳合法候选。

几何验证独立于搜索，检查所有件、包含、真实外轮廓重叠与设定间距。优化是启发式，不声称全局最优。面积利用率由面积/板数计算，固定板数时不能虚构增益。原 CAD 只有通过当前约束验证后才可作为可行候选。

验收：实际样例 3 张 1220×2440 板，25/16/12 件，共 53 件，28 个通孔、29 个浅槽；P42/P45 为 348×792mm 且包含直径25mm圆孔；真实曲线和孔槽随重排一起移动；P16/P17 间距3mm应在6mm间距设置下报警。重排后所有件完整、无重叠、满足板框与用户约束；三种评价规则可实际区别布局；应用/撤销保持源模型。拒绝错误 DXF 与不完整导入，交互在桌面与窄屏均可使用。测试重点是导入几何和布局正确性，样式通过浏览器验收。
