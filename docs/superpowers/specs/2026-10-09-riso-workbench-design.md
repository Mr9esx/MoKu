# 木作 · 双色印刷工作台

用户提供的建筑海报是本次视觉改造的依据：米白纸底、钴蓝与朱橙双色、网点印刷质感、粗宋体与英文衬线体。直接用于现有 React 工作台，不新增独立营销页面。

## 设计

- 欢迎页采用左侧大标题、右侧木作框架轴测插画，底部用编号说明导入、排布、导出三个步骤。提供导入 DXF 和打开示例两项实际入口。
- 品牌、面板标题、弹窗标题采用本地托管的 Noto Serif SC 900，英文数字采用 Times New Roman。表单、尺寸和操作说明使用清晰的系统字体。
- 米白背景、蓝色细线与近直角面板构成统一工作区；朱橙用于主要导入操作、待放置和选中零件。取消原有绿色、木黄色视觉。
- 网点只用于装饰插画和淡背景。真实图纸保持清楚的轮廓、孔槽、选中与磁吸语义。
- 空白概览说明三个步骤；真实项目概览继续展示现有计算结果。桌面保留左右资源与信息栏，移动端保留资源、画布、信息切换，欢迎页可以滚动。

## 边界与验证

不更改导入事务、几何计算、自动排版、撤销或 SVG 导出。无需新的框架或运行时依赖。验证生产构建与现有测试，并在浏览器检查空白页、示例导入、真实图纸、选中零件、弹窗及窄屏布局。字体附上许可；字体未加载时有系统宋体回退。
