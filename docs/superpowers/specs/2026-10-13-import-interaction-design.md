# 导入交互优化

用户已认可上一轮审查方案并要求实施。保留固定的左侧预览、右侧确认布局。

- 左侧统一承载原图与导入结果，单位在预览工具栏直接修改。选择板材、图形与参数卡片联动。
- 右侧顶部提供单一“导入配置”入口，统一示例格式与已保存配置；保存与管理按需展开。
- 删除“自动处理与导入选项”。修正、忽略和其他提示进入独立“图纸检查”，不与配置混放。
- 待确认按处理组计数，组数与涉及图形数分开显示。设置统一为填写后确认；已完成组可回看和修改。
- 图层批量修改明确覆盖当前空间本层的图形设置，保留文件级几何来源，其他空间与图层的单独设置不修改。
- 保存配置使用当前空间图形的实际用途。只保存同层统一且完整的加工配置；混合、未确认或缺少加工参数的图层明确列出，不保存图形标识或原图数据。
- 应用配置保留手工设置，反馈实际应用图层与保留的单独设置数量，避免宣称所有内容已被替换。
- 底部主按钮根据状态引导确认图形、填写参数或执行导入。未填写参数时点击引导到具体缺项，全部有效才提交。
- 切换图纸类型保留用户输入；必要的独立校验和替换项目提示保留。

验证：配置保存的混合图层、几何来源、未知用途、槽宽槽深、跨空间隔离；组数与实际待确认卡片一致；真实文件与示例图纸的浏览器导入流程；构建和相关回归测试。
