# 排版与组装的信息栏布局

用户已选择：固定右侧信息栏，两个工作区一起整理。

## 空间划分

- 保留顶部固定工作区切换与左侧 248px 资源栏。
- 预览外框内部使用两列布局：中间画布 `minmax(0, 1fr)`、右侧固定信息栏 304px；901–1200px 窗口的信息栏统一为 260px。
- 实际 SVG / WebGL 容器、画布标题、图例、空态、视角立方体与所有画布操作放在独立的 `preview-main` 内。右侧 `preview-information` 为兄弟节点，拥有独立背景与分隔线。
- 信息栏简版、零件属性、详情和检查均保持同宽。展开内容在栏内滚动，不改变画布宽度或覆盖画布。
- 适应全部基于实际画布尺寸。已有缩放、平移、磁吸、撤销和装配操作保留。

## 控件占位

- 标题在画布左上，图例在画布右上。
- 编辑工具在画布底部中央，视图切换在其上方；视角立方体或缩放工具在画布右侧，并随画布自身宽度响应。
- 当画布不超过 560px 时，缩放工具 / 视角立方体提升到独立高度，避开底部编辑工具；不使用信息栏宽度偏移来推算控件位置。
- 组装空态只在画布中展示一处简短操作指引。信息栏显示组装概览与数量，不重复欢迎文案；必要检查提醒仍然保留。

## 窄屏

- 900px 及以下沿用资源 / 画布 / 信息切换；画布与信息分别占满同一个区域。
- 信息页隐藏画布交互，画布页不叠加信息面板。切换详情不创建第二层覆盖。

## 验证

检查空组装、已放入零件、选中零件、展开 / 收起详情、二维概览与零件属性。验证 1537px、1024px 和 320px 布局：画布与信息栏不相交，视角及编辑控件不进入信息栏，展开前后画布宽度一致。执行现有回归测试和构建，不修改此前清角相关工作。
