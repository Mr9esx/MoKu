# 导入列表与单图形处理优化

**目标：** 展开后的下拉列表与平台一致；逐个处理时能清楚分辨图形、问题和设置。

**实现：** 共用带 listbox 语义的 Select，弹层在视口内定位，支持方向键、Enter、Escape、Tab 和点击外部关闭。沿用材料选项的来源与现有导入数据处理。逐个处理改为按图形分开的卡片，展示缩略图、编号、尺寸、问题及原位设置。

- [x] 复现系统菜单风格差异与重复图层信息造成的布局问题。
- [x] 实现共用下拉组件并接入导入用途、槽画法、单位、空间、模板、板框、材质和导入方式。
- [x] 整理独立图形卡片及原始/修正路径操作；保留批量设置和单图形设置的原有行为。
- [x] 浏览器验证菜单键盘行为、滚动和边界定位、真实图纸单图形修改、窄屏布局及截图。
- [x] 构建、相关回归测试与差异检查。
