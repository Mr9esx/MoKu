# 装配移出入口优化

**目标：** 选中已放入场景的零件，右侧默认卡片直接显示「移出组装」，无需进入精确调整。

**设计：** 在紧凑卡片的「当前零件」标题右侧显示带图标、使用现有强调色的文字按钮。仅对已加入的零件显示；装配只读时禁用。悬停说明「保留左侧零件，可撤销」。继续使用现有 `commit` 事务，因此保留零件库、配合规则及撤销能力。详细面板保留原入口，两个入口共用同一移出回调。移出后保持选择，卡片展示「放入场景」，可立即重新加入。

**范围：** 修改 `AssemblyInspector.tsx` 和 `assembly.css`，更新 `AssemblyCanvas.tsx` 的撤销说明，使其覆盖移出操作；不添加快捷键、确认弹窗或新工具栏。此次仅提升现有操作入口，不增加状态管理或业务规则。

- [x] 将原移出操作提取为组件内共用回调，在紧凑卡片增加直接入口。
- [x] 添加紧凑按钮样式，保持原有卡片密度。
- [x] 在独立示例页验证可见入口、移出、重新加入及撤销；不修改用户原页面数据。
- [x] 运行装配回归测试、构建及差异检查。
