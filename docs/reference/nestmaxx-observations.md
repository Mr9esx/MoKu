# NestMaxx 工作区参考观察

来源：https://nestmaxx.com/zh/ → 打开 NestMaxx。使用 Computer Use 实际操作，2026-10-08。

工具界面为固定高度全屏点阵画布。顶部紧凑品牌栏与板材尺寸；左上黑色排样主按钮；左侧悬浮可收起零件列表，含轮廓缩略图与尺寸；选中零件在右侧展开属性。底部中央悬浮图标工具条、右下角缩放与适应控制、底边状态栏。设置和板材设置使用中央模态弹窗；点击排样先打开快速参数确认弹窗；导出使用右侧抽屉。实际操作观察了新增来源、零件选择、设置标签、板材设置、快速排样、导出抽屉及画布快捷键说明。

本站沿用木作品牌和真实 tan/sage/blue/pale 孔槽颜色，以此工作区结构替换先前长页面。用户明确追加：工具栏 DXF 导入，左侧识别组件，右侧原始布局，新增单个组件、新增板材、拖动布局、弱磁吸和对齐。

第一阶段矩形和圆形为自建组件入口；保持毫米单位与真实材质/板厚约束。任何未实现的 NestMaxx 形状库、内置 CAD、SVG 导入或分享功能不放假按钮。算法保持本站已验证的有限预算引擎。
