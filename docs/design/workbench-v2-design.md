# 木作工作台：整体布局与交互重设计提案

状态：供讨论的设计方案。生产代码与线上版本未修改。独立原型为 `workbench-v2.html`，仅演示信息切换和入口流程；布局轮廓为示意，统计采用随附样例数据，不执行导入、编辑或排版。

## 目标与诊断

面向用多层板自制家具的用户，核心路径是导入图纸/零件 → 核对资源 → 手动调整 → 自动排版 → 比较与应用 → 导出。当前界面有四个结构问题：

1. 顶部同时承载项目入口、资源创建、画布操作和面板开关，用户很难从位置判断操作对象。Logo 移到左侧，使顶部缺少项目身份，左侧列表又多了一层装饰区。
2. 左侧是持续使用的零件资源，折叠增加隐藏状态；顶部新增零件和板材与左侧资源列表脱节。导入结果在左侧出现，入口却在顶部。
3. `analysisOpen` 与 `selected` 共同决定右侧内容，形成多余的显示组合。关闭概览后取消选择会出现空右侧；右侧关闭/恢复使画布宽度变化。目前画布空白指针事件开始平移，没有短点击取消选择逻辑。
4. 导入语义不完整。当前 `importDrawing`/`finishImport` 为整个项目载入流程；DXF 解析依赖 `REF_STOCK` 板框及明确加工图层。独立零件不能用相同入口直接假装支持。

启发式专家评估约 6/10，主要问题为操作位置与对象不匹配（严重度 3）、独立零件导入缺失（3）、多余面板状态（2）与品牌位置（1）。这不是用户测试评分。方案要在真实导入、定位、拖动、候选比较任务上验证，不能只以外观判定改善。

## 布局选择

- 推荐：固定三栏，保留现有轻量浮动外观。左侧资源，中间画布，右侧上下文信息。改动符合已有用户习惯，信息位置稳定。
- 可选：完全贴边的 CAD 工作台。可容纳更多信息，但视觉更重，没有必要在本轮替换用户已认可的浮动形态。
- 可选：导入/编辑/排版分步页面。适合第一次操作，但频繁回看零件和比较结果需要跨页，降低手动编辑效率。

选用第一种。桌面顶部 42 px，按钮 32 px，保留 RiSu 的密度与轻边框。左侧约 248 px，右侧约 286 px，面板齐平、相同圆角和留白，内部独立滚动。中间获取剩余空间。选中与取消选择只换右侧内容，不改变面板宽度、画布尺寸、缩放和平移。

## 各区域职责

| 区域 | 保留内容 | 迁移/删除内容 |
| --- | --- | --- |
| 顶部左侧 | Logo、木作、项目名；导入/排版过程状态可替代项目副标题 | 左侧 Logo/title 移到这里 |
| 顶部中部 | 选择、平移、磁吸、撤销 | 移除导入、新建零件、板材管理、数据开关 |
| 顶部右侧 | 自动排版（主要动作）、导出、更多 | 恢复原图、示例、帮助收进更多，恢复说明影响范围 |
| 左侧 | 导入 DXF；零件/板材页签；搜索、数量、资源列表与对应新增入口 | 不折叠整个侧栏，标题不做折叠按钮 |
| 中间 | 原始/当前/候选布局；拖动、弱磁吸、对齐参考线 | 避免候选长提示遮挡板材 |
| 右侧 | 数据概览或选中零件的信息 | 移除数据分析按钮、概览关闭按钮、右栏开关 |
| 底部中间 | 原始图纸 / 当前排版 / 候选方案 | 未生成候选时禁用并说明原因 |
| 画布右下 | 缩放、适应全部板材 | 磁吸放顶部编辑工具组，避免重复 |
| 页底状态 | 检查结果、必要快捷键提示 | 不重复所有统计、长文件名与操作说明 |

左侧默认零件页签，显示已放置/待放置计数、名称、尺寸、板厚和所在板；待放置零件显示明确状态，不用“板 0”。板材页签显示尺寸、板厚、材质、使用零件数；新增/修改/删除在资源的附近执行。删除空板可撤销，有零件的板先移走零件，不隐式删除零件。

项目名优先显示用户原文件名；如多文件组成项目，显示项目名，文件来源保留在零件信息里。界面术语统一为“零件”和“板材”。

## 两种导入

左侧单个“导入 DXF”入口打开两个清楚的选项，不放两个同样醒目的常驻主按钮。

### 整板图纸

指带板框和已有排版的图纸，允许一个文件包含多张板，不是限制为一张。

选择文件 → 预览识别的板框/零件及异常 → 核对单位、每板厚度与材质 → 确认导入。

首次导入创建项目并保留原布局。已有项目时明确选择“追加到当前项目”或“打开为新项目”，不默默替换。打开新项目时，保留当前项目的恢复入口；若持久化尚未实现，必须说明替换范围并确认。追加导入应作为一次可撤销事务。

### 零件轮廓

选择文件 → 预览独立闭合外轮廓与孔槽 → 输入板厚、材质、数量（尺寸由图形解析） → 追加到待放置零件。

不要求 1220 × 2440 板框；不自动新增板材，不自动修改已有排版。通过拖入兼容板材或自动排版放置。单位缺失时要求选择单位，显示转换后的毫米尺寸预览；板厚不能默认猜测。未闭合/拓扑不明确的轮廓列入异常，明确排除数量，让用户核对，不能静默吞掉。包含关系和孔/浅槽语义分别核对，不能将所有内部轮廓一律视为通孔。

两种路径共享文件读取和解析预览组件，但入口语义、确认字段与写入行为不同。取消预览不修改项目；解析期间有进度和取消；读取失败保留当前工作。

## 右侧仅两种状态

| 触发 | 右侧 | 列表/画布 |
| --- | --- | --- |
| 首次打开、未选中 | 当前视图的数据概览 | 没有零件高亮 |
| 点击列表零件或画布零件 | 该零件的信息 | 对应列表行和画布轮廓高亮 |
| 点击空白画布或板材空白 | 恢复数据概览 | 清除零件选择 |
| Esc / 返回概览 | 恢复数据概览 | 清除选择，不撤销编辑 |
| 拖动零件 | 零件信息持续展示 | 不因松手清空选择 |
| 拖动平移、缩放或使用工具栏 | 保留当前上下文 | 不误触取消选择 |
| 切换原图/当前/候选 | 同一零件存在时继续选中，否则恢复概览 | 内容取当前视图；原图/候选只读 |

空白短点击与拖动平移必须区分：在 pointer-up 判断位移阈值（例如 4 px）；不能在所有 pointer-down 时无条件取消。Esc 在弹窗或拖动过程中优先取消当前操作，再在空闲时取消选择。切换左侧页签不修改布局或自动重排。

## 数据层级

默认概览第一屏回答“用了几张板、利用率多少、零件是否放齐、有无问题”。轮廓利用率和使用板数为主要指标；净利用率、已放/总数作为次级指标。明确展示未放置数量、冲突/越界/间距警告，警告可定位零件。

第二层是每板利用率、厚度与零件数；再往下是面积、余料、加工空移和视图比较。当前布局板面积与库存板面积保留，详细说明通过轻提示/详情展开，避免第一屏铺满相近数字。原图/当前/候选必须使用各自真实指标，前后比较时展示零件集合变化；不能把新增零件或库存改变产生的百分比差异表述为算法优化。

候选生成后，概览顶部增加“候选 vs 当前”的用板、利用率、余料/行程变化，明确显示“应用候选 / 放弃”。只有应用才改变当前布局；搜索中的取消保留已有编辑。选中候选中的零件时右侧切到零件信息，搜索/候选状态通过顶部轻提示和底部候选标签保持可见。

零件信息展示名称、轮廓预览、宽高/板厚、材质、所在板/待放置、孔槽、旋转与来源；操作为锁定、旋转、复制数量、删除（可撤销）。原图/候选中编辑操作禁用并说明只读。不能将轮廓、间距检查包装成家具装配验证。

## 空状态与异常

未导入时左侧显示“导入整板图纸 / 导入零件”，中间简短引导，右侧显示待导入状态，不自动装入示例；示例是更多菜单中的主动入口。已导入零件但没有板时提示“先新增板材”，库存与待放置数量如实显示。零件大于所有板时保留待放置状态，指出兼容尺寸/厚度问题。

新建零件和板材有局部表单；导入与排版设置使用临时弹窗。右侧常驻信息不因表单打开而永久消失。导出当前布局时，未放置或非法布局应阻止“全部零件已完成”的误导输出；如后续提供部分板导出，必须明确选择范围与缺失零件。

桌面优先。窄屏改为资源/画布/信息的页面区或显式切换，不把两侧浮动卡片直接叠到画布上。左侧不折叠的规则保留在桌面工作台；触屏布局要另做验证，不假定 32 px 控件足够触控。

## 实现边界与验证

现有 store 的源图不可变、undo 事务、过期 Worker 结果保护和几何校验继续保留。需要移除折叠与 analysisOpen UI 状态，右栏由有效选中项驱动。补充空白短点击选择状态规则，拖动/平移回归必须覆盖。

独立零件导入需要新增没有板框的解析路径、稳定材料/厚度身份、未放置资源集合，以及搜索/检查/指标/导出对未放置零件的语义。整板追加需要对象 ID 重映射和导入来源记录。多次导入保留各文件不可变快照；“原始图纸”展示当前项目所有整板来源的原始布局集合，独立零件显示为原图中未放置，编辑布局独立保存。前后比较始终说明集合与用板口径。

实施可分两步：先完成工作台信息层级、固定面板和选择联动；再完成双导入路径与待放置流程。上线时“零件导入”必须真正支持独立文件，不能仅增加未实现按钮。

验收任务：首次整板导入；无板零件导入→新增板→放置；追加不丢原编辑→撤销；列表与画布选择联动→空白恢复；平移不取消选择；三个排版模式生成、比较、应用与撤销；非法/未放置零件的检查和导出提示；原图只读；面板切换不改变画布坐标。

## 本轮设计交付与检查

- 原型 `workbench-v2.html`：可体验零件选择、空白取消、资源页签、两类导入说明。其他操作打开设计说明，不执行真实业务。样例形状为简化示意，非 53 个实际轮廓。
- `workbench-v2-overview.jpg` / `workbench-v2-selected.jpg`：默认概览与选中零件状态。
- 原生浏览器验证：选择 P42 后展示 348×792×5 mm / 单通孔；点击画布空白后回概览；画布宽度始终 698 px，右栏 286 px。两种导入入口可区分。
- 本提案未经真实用户任务测试，不宣称已达到 10/10；线上应用没有改动。
