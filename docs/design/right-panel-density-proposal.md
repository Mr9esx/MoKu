# 右侧信息密度优化提案

状态：用户确认后已接入正式工作台。独立原型仍可在 `/demos/right-panel.html` 查看。

## 问题

286 px 侧栏连续展示总览、净利用率、检查、每板尺寸/材质/板厚/轮廓率/净率/余料、加工详情、三种视图表格及口径说明。每板重复的规格和比例使用户需要在相近数据间反复扫视。选中零件时，大预览和六行属性挤压编辑入口。

## 可选方案

1. **摘要 + 渐进展开（推荐）**：两个主指标与状态常驻，每板收成一行，技术数据按需展开；候选出现时提供概览/对比切换。只增加查阅细节的一次点击，保留同一右栏。
2. **概览/板材/加工三页签**：首屏最少，但常用用板信息被拆到另一个页面，需要更多切换。
3. **增宽侧栏**：可减少换行，但挤压画布，重复指标仍存在。

## 推荐方案

- 侧栏保持 286 px，与现有工具栏、色彩、字体一致。利用率定义为轮廓利用率，使用/库存板数明确；净利用率和面积口径保留在指标详情。
- 检查通过归入工作台底部全局状态栏，可点击查看检查详情；右侧移除重复的成功提示。待放置、几何问题、资源集合不同和只读限制保持显式显示，不收进详情。
- 每板默认仅名称、使用率、窄进度线。展开后显示尺寸、材质/板厚、零件数、净率和矩形余料。避免复制左侧的完整库存卡片。
- 面积、余料、加工空移集中到一组指标详情；不再常驻三视图横向大表。
- 仅存在候选时提供“概览 / 对比”。对比默认候选 vs 当前，两列明确展示用板、轮廓率和估算空移。原图比较通过基准选择器切换。未放齐/库存集合不同则先说明可比性；不声称算法带来不可比的提升。
- 零件标题旁显示 96 × 124 px 轮廓预览，宽高作为主信息；板厚与材质同一行，位置一行。锁定/旋转常驻，孔槽/槽深/来源放入加工与来源详情。复制数量、复制、删除移至更多操作。
- 待放置时目标板与放置动作直接展示。只读视图显示提示并禁用编辑。完整业务约束仍由现有 store 和几何校验处理。
- 未导入时图示、提示文字与帮助按钮居中，仅保留简短引导，移除虚拟指标 0/—、重复操作说明和品牌口号。

## 原型与验收

原型默认仅展示新版，勾选“显示改前对比”后展开等宽比较；包含概览、已选零件、待放置、候选、警告与空状态六种场景；折叠区域、对比基准、板材详情和操作菜单可交互。使用示例图纸统计，候选空移取既有验证记录；未执行真实排版，不修改正式项目。

正式接入应验收：警告不会被折叠；孔槽与来源可查；只读编辑禁用；待放置动作可见；基准与资源差异说明正确；选中/取消不改变画布大小；窄屏详情可展开。

## 原型验证与用户修订

- 等宽概览默认展示：现状内容高度 1029 px，提案内容位于 507 px 的可视正文内；每板详情展开可见尺寸、材质、数量、净率和余料。
- 原生浏览器验证：复制菜单与数量输入、候选比较基准切换、异常定位到待放置场景、目标板材选择和模拟放置均可操作；控制台无 warning/error。
- 根据用户反馈，未导入场景的图示、提示和帮助按钮居中；零件预览由 50×61 px 放大为 96×124 px，仍与标题及尺寸并排。默认选中面板正文无纵向溢出。
- `pnpm build` 和 `git diff --check` 通过。此处为原型阶段记录；正式接入验证见下文。
- 截图：`right-panel-overview.png`、`right-panel-selected.png`、`right-panel-empty-centered.png`、`right-panel-part-enlarged.png`，均位于本目录。

- 校验提示修订：默认收起改前面板，避免旧文案与新版混淆；底部使用“排版检查：通过”，成功检查项通过详情查看。

## 正式接入

- LayoutAnalysis 使用真实统计：默认摘要与每板折叠详情，指标详情收纳净面积、库存、余料与空移。候选默认对比，首屏为用板数、轮廓利用率和估算空移；净利用率、布局面积和可用余料在对比详情中。

- 未导入状态居中；桌面侧栏宽度与画布几何不变，窄屏有 40 px 折叠入口。
- 真实样例、候选基准、应用撤销、复制待放置、检查定位、兼容板选择、删除撤销、只读和移动端验证详见 `../verification.md`。
