# 板材表单布局与输入交互

2026-10-08，用户认可单张编辑与新增分离的方案，并要求优化输入交互。

左侧资源面板管理库存，单张板材「设置」携带板材 ID 打开编辑弹窗；「＋」打开独立新增弹窗。编辑只呈现板名、只读尺寸、已放零件数和板厚/材质字段；新增提供名称、宽高、板厚、材质。删除仍留在左侧，右侧数据概览不承担表单任务。

表单保持本地字符串草稿，不在输入/失焦时修改库存或生成历史。数字支持清空重填、小数、全角数字；失焦只规范有效数字，无效内容保留并显示字段级错误，保存时聚焦首个错误。输入使用 decimal 键盘提示，没有滚轮步进；文本材质可参考已有库存建议，也可自由输入。名称/材质保存前去除首尾空白。

新增初始聚焦名称，编辑初始聚焦并选中板厚；Tab 限定在弹窗内，Enter 提交，Esc/取消/关闭丢弃草稿并恢复入口焦点。中文输入法组合过程中 Enter 不提交。未修改时保存禁用。板厚或材质变化且已有零件时，说明保存会同步本板零件。

板厚和材质由一次事务保存，同步当前库存、当前布局以及当前放在目标板上的零件，一次撤销恢复两项属性；其他板和待放置零件不受影响。无变化、无效参数或只读视图不写入历史。导入原图快照保留。

弹窗宽度 480 px，字段正文 14 px、摘要/错误/说明 12 px。标签放在字段上方，宽高成对，板厚与材质成对且材质更宽。正文在小视口内滚动，底部操作固定可见，不随板材数量增长。
