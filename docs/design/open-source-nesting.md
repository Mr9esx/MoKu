# 基于 SVGnest 的排版引擎

2026-10-09

## 主次关系

生产入口 `src/core/nesting.ts` 仅负责参数检查、业务评分、已验证最佳方案和结果发布。
所有新排法由 `src/core/svgNest.ts` 的 SVGnest NFP 放置与遗传搜索生成。
不再给旧算法分配搜索时间，也不再对 SVGnest 结果调用旧压紧、跨板 DFS 或局部交换。
旧实现保存在 `tests/support/local-nesting-baseline.ts`，仅用于回归对照，应用代码不引用它。

```mermaid
flowchart LR
  P[原始轮廓与真实库存] --> A[板厚 / 材质 / 间距 / 锁定约束]
  A --> N[SVGnest NFP 可放置区域]
  N --> G[SVGnest 遗传搜索：顺序 + 旋转]
  G --> F[用板 / 加工 / 余料适应度]
  F --> G
  G --> V[原始轮廓独立校验]
  V --> B[最佳完整候选]
```

## 采用的上游

- SVGnest: https://github.com/Jack000/SVGnest
- 固定版本：`1248dc21efd3f90d1aa52ba5785e27e5217ed2c9`，MIT。
- 遗传算法直接提取自 `svgnest.js`；NFP 和放置流程移植自该文件及 `util/placementworker.js`。
- 默认种群 10、变异率 10 与上游一致；加入独立随机排列和停滞重启，保留精英。
- NFP 采用上游默认 Minkowski 路径。仅凸轮廓使用计算结果等价的线性边合并加速；凹轮廓保留凹槽。

## 必须保留的产品规则

同板厚、同材质的全部未锁定零件参与整体重排，原来的板归属不限制搜索。
每个零件仍使用真实外轮廓，允许的旋转为 0/90/180/270 度；禁用旋转则为 0 度。
板厚和材质构成独立搜索组；各组包含所有兼容零件和真实库存。耐心模式轮流推进每组一代，保留各组种群、精英、随机状态和 NFP 缓存；全组完成一代才计一次耐心。时间/代数模式仍按组累计代数、共享时长。完整候选合并各组最佳已验证布局。库存有限，尺寸逐板判断；锁定零件是固定障碍，不改变位置、角度或板归属。
孔槽保留用于验证和导出，当前不开放孔中放件。

三种模式用同一引擎，只改变遗传适应度。利用率模式先减少实际使用板材面积（完整零件集合固定时等价于提高利用率），面积相同时再减少板数，避免把两张小板换成一张很大的板却降低利用率。加工和余料模式用板数优先；余料模式按板厚/材质分组扩大最大连续矩形余料，
相同时按库存顺序填前板。加工模式比较中心访问空移估算。完整布局通过独立校验后才能显示为候选。
已合法的当前排版是安全基准，不是限制搜索的起点；找不到更好完整排法时保留它。

## 时长与几何计算

界面默认连续 50 轮没有改善时停止，可设置 1–1000 的整数。利用率模式严格按最高已验证轮廓利用率判定；加工模式依次比较板数和预计空移；余料模式依次比较板数、各组最大连续余料、库存顺序的前板填充、可用余料总量。当前目标改善后计数归零，轮廓位置等辅助排序改善不重置计数。每个仍可搜索的材质/板厚组都完成一代才计一轮；搜索不受旧时间和总代数上限截断，手动停止仍可终止 Worker。连续无改善不构成最优性证明。

曲线以零件实际外轮廓面积除以实际使用板材面积为指标，观察完整、独立合法的候选，即使某候选被所选业务目标拒绝，也记录其更高利用率。未出现合法完整方案时显示“待验证”，不虚构零利用率。曲线保留至搜索结束或手动停止；最多保留 2048 个历史样本，计数器始终精确。

可另选时间与代数限制（1–300 秒、每组 1–100 代，先到者停止）。旧核心调用未传 stopRule 时保留此有限模式兼容性；网站明确初始化为 patience。
复杂轮廓的初始 NFP 计算会占用时间。缓存后其他排列可复用同一 NFP。
大 Minkowski 计算分批求同一个 union，在批次间检查时长；停止后的不完整 NFP 不会被使用。
原始轮廓校验和单次几何操作可能导致实际用时略超设定。

去掉了复杂轮廓凸包粗排：原来凹 L 形增加采样点后会退化为两块板，新测试要求保持单板嵌合。
清理仅去掉半个整数单位内的重复/共线点，精度为 0.0000001 mm，不用形状粗化换速度。

## 搜索中的预览与交互

画布上方的排版状态卡只保留「正在排版」、模式、当前组/代数、已用时间与停止按钮。准备和收尾阶段显示简短阶段词；移除重复的实时试排标签、厚度材质、每次排列编号、件数和编辑/校验说明。耐心进度由右侧利用率曲线展示。

排版设置直接在三个模式按钮中说明用途：利用率优先减少用板面积，加工优先减少预计空移，余料优先保留连续大块余料。移除引擎/遗传搜索介绍、重复曲线、导入消息和多段停止说明；只在停止条件旁保留当前模式的一句判定说明，错误消息仍显示。

设置弹窗宽 560 px，模式以三条纵向选项展示，标题/参数为 14 px、说明为 13 px。窄屏选项采用标题加说明的两行布局。参数区独立滚动，标题及底部操作保持可见，字段和单位不得覆盖操作栏。参数分为「排版目标」「加工约束」「可用余料」「停止条件」；零件间距注明需大于或等于刀径。旋转开关改为「允许改变零件方向」，列出实际支持的 0°、90°、180°、270°，没有增加任意角度旋转。

停止条件使用两个单选选项，仅展开所选方式的输入：「连续没有改善时停止」把数字嵌入「连续 [50] 轮没有更好的排版时停止」，判定说明随模式切换；「达到时间或次数上限时停止」分别输入最长时间和每组最多搜索轮数，并注明达到任一上限即停止。输入范围和整数约束保持一致。曲线仍绘制最高实际利用率，停止进度则显示本次搜索的目标；目标随结果保留，手动停止后不丢失。

「当前排版」展示一代内最近完成且完整可行的一次整套试排。缺件或不合格的尝试仍参与搜索，但不替换画布。SVGnest 每次排列评估结束发布实际布局，Worker 先过滤未完成试排，再按约 300 ms 的显示间隔取最新完整尝试，快速计算合并掉中间画面，慢速尝试完成后直接刷新；已有心跳会及时发布尚未发送的最新布局。只保留一个待发快照，不积压回放，不等待动画完成，也不固定每 20 次尝试取样。整套快照之间同时平移/旋转过渡 240 ms，孔槽和标注随零件一起移动，跨板转换到统一画布坐标。每次插入的 SVG 动画显式起播；不积压动画队列，不等待动画完成，不改变搜索输入。没有逐件回放和播放设置，系统减少动态效果偏好会关闭过渡。

画布、用料清单、零件信息同步试排位置和已放置数量；指标与检查始终对应最佳完整方案。主线程独立校验每个零件恰好一次，拒绝缺件、未知零件、库存/材质/板厚/锁定错误、重复零件以及间距、重叠和边界问题。只有完整合法的试排才显示，未通过时保留上一套完整画面。试排不能写入候选结果或撤销历史。没有试排时显示最新合法候选或当前布局，停止或结束后清除试排、保留最佳候选，应用才正式写入。

搜索中禁止修改输入：零件移动/旋转/锁定/复制/删除/新增、板材规格/增删、参数和模式、导入、撤销与恢复。状态层同时拦截快捷键、拖动结束和旧弹窗等入口；禁用按钮提示停止后可修改。导出暂不可用，避免导出的已应用布局与实时画布不一致。底部选择/平移/磁吸/撤销全部禁用，V/H 快捷键、画布指针拖动与点选也暂停，进入搜索时清除未结束的拖动。缩放、滚轮浏览、资源列表点选查看、原图对照、参数查看与停止搜索保持可用。橙色「正在排版」卡片、持续活动线和板材边框动效表示搜索进行中，不表示完成百分比；结束后自动移除。画布适应布局动态测量真实浮层高度，避免状态卡遮住板材。

## 效果与边界

遗传搜索通过交叉、变异和独立种群探索新组合，能跨越单件搬移不能通过的中间状态。
它仍不能保证全局最优，也不能保证每次限时搜索都优于当前布局。
上游 README 的性能描述以约五分钟搜索为参照，不能用短时间测试声称达到所有商业或开源算法的最佳效果。

选择 SVGnest 是因为它已有浏览器实现、凹多边形 NFP、遗传搜索和可适配的多容器流程。
Sparrow Studio 当前文档注明不自动分配多板；libnest2d 文档注明当前主要支持矩形和凸多边形。
这些差异影响本项目接入成本，并不构成普遍的算法排名。

## 验证

测试覆盖凹轮廓嵌合、密集共线采样、实际间距、锁定障碍、不同库存尺寸、材质/板厚隔离、
有限库存、整体跨板交换、余料集中、固定种子复现和中途停止。
实际图纸的可行性和搜索效果独立记录在 `docs/verification.md`，不把保留原图误记成优化成功。


### 排版检查中的修复流程

“生成修复候选”使用同一个 SVGnest 引擎。首先释放间距、重叠或边界问题涉及的零件及其相邻零件，其余已放置零件作为临时障碍。耐心模式下两阶段分别按相同耐心规则搜索；首阶段没有完整合法候选时，扩大到全部未锁定零件重排。有限模式下首阶段占整体时长的 75%，没有合法候选时在剩余时间内扩大重排。这样小问题可避免重排整张图，同时保留扩大搜索范围的路径。

临时固定状态只用于搜索，发布前恢复用户原锁定状态并重新独立验证。修复不改变用户间距、边距、库存和材质/厚度条件。未找到候选时保留当前排版；通过检查的候选需应用后生效，可撤销。几何合法性与文字归属分别展示：唯一的文字/轮廓包围框对应自动关联，歧义关联保留提示及原坐标。
