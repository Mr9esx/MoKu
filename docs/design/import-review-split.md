# DXF 导入弹窗分栏

桌面左侧固定显示 CAD，右侧独立滚动；窄屏固定上方图纸、下方操作区。文件选择和最终确认常驻。

右侧默认展示待确认项，每组带缩略图、图层名称及数量。点击分组会高亮对应图形并展示批量设置；逐项查看可放大单个轮廓并单独编辑。其他图形淡化。“对象与去向”改为“全部图形”，“定位”改为“在图中查看”。

图层与图形、板厚与材质分别查看。自动处理记录、模板、兼容预设与格式说明折叠展示；缺少单位时直接展示单位输入。缺少参数时自动打开参数页并聚焦首个错误字段。参数中的板材预览联动左图。编译失败保留具体错误，不显示可继续导入。

## 验证

用户 DXF 本机读取得到 54 个图形、4 组未确认用途；选择 8 个内部图形得到 8 个高亮，逐个查看可放大单个轮廓。使用测试用途及深度核对后仍生成 2 板、42 件、39 个已放置、3 个待放置。测试参数不代表原图加工结论。

实际浏览器验证：参数报错聚焦“板材 1 导入板厚”；选择“预览板材 2”保持参数页并高亮对应板框；320 × 740 视口无横向溢出，图纸保持可见。合成的单位缺失文件直接展示单位输入。浏览器无 warning/error。未改动用户已有标签页。

截图：[桌面](import-review-split.png)、[单个图形](import-review-split-selected.png)、[窄屏](import-review-split-mobile.png)。

仅重排界面，保留图层、单图形、批量设置、模板、原路径恢复、单位换算、待放置参数和导入事务逻辑。

最终验证：`pnpm exec vitest run --maxWorkers=1 --no-file-parallelism`，29 个测试文件、449 项通过；`pnpm build` 和 `git diff --check` 通过。构建仍有已有的主包体积提示。全部图形被明确忽略时，浏览器展示“暂时无法导入”及具体原因，导入按钮禁用。
