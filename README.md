# 木作 / 图纸工作台

浏览器内运行的木作 DXF 图纸与 3D 组装工作台。先导入图纸，再编辑榫槽细节、安排用料、搭建成品或导出二维零件图纸。React 19、TypeScript、Vite、Zustand。默认空工作区；「更多 → 打开示例图纸」预览真实 3 张 1220 × 2440 mm 板材、53 个零件、28 个孔和 29 个槽。示例也需确认材质后导入。

## 运行

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

开发地址 http://127.0.0.1:4190，生产输出 `dist/`。导入与排版分别运行在 Worker 中，DXF 文件不会上传。工作仅保存在本页内存；刷新会丢失，暂无持久化后端。

生产站点：<https://moku.miaoplus.com>。发布与回滚见[部署说明](docs/deployment.md)。

## 双导入与源图

左侧「导入 DXF」选择整板图纸或零件轮廓。文件先进入独立预览；取消、解析错误和单位修改不更改工作项目、历史、候选或正在运行的搜索。确认才执行一个可撤销事务。已有项目明确选择追加或打开新项目；打开新项目也可撤销恢复上一项目。

- **整板图纸**：可含多张正交矩形板框，无需重命名 CAD 图层。确认板框后，唯一落在板内的零件保留坐标，框外零件进入待放置区，孔槽随所属零件保留。逐板确认厚度和材质；框外件独立输入这些参数，也可明确点击按钮采用所选板材参数。跨板或多板归属必须单独处理。
- **零件轮廓**：无需板框，已确认的板框只作为原图参考。所有零件加入待放置区，独立输入板厚、材质和每种轮廓的数量（1–100，总计最多 1000 个）。可用 `/standalone-parts.dxf` 测试：200×100 mm 带直径 25 mm 孔及深 3 mm 槽，另一个 120×80 mm 零件；按图层确认用途与深度后导入。

追加是纯合并事务，对新板材、零件和全部放置引用统一重新映射 ID，避免重复导入冲突。原图是各导入来源的组合，另保留各文件几何快照；独立零件在原图中仍待放置。工作项目的材质和来源记录在零件自身，删除板材不会抹去身份。手动新增/复制/删除、材质/板厚、锁定、移动、旋转、导入、应用与恢复均可撤销，历史包括源图基线。

## DXF 约定与边界

导入分为文档读取、几何归一、工艺核对、Project 构建四层。支持 ASCII DXF、二维 LWPOLYLINE / POLYLINE、圆、椭圆、控制点/正权重样条、LINE / ARC 链（开放链需确认槽的画法），以及嵌套块（基点、旋转、镜像、非均匀缩放、阵列）。保留原始图层、实体来源和模型/布局空间。曲线按 0.025 mm 误差界采样，使用 dxf-parser 解码与 b-spline 的有理 de Boor 求值。

任意图层名称可以进入预览，上传文件的用途默认未确认。CUT / INSIDE / POCKET 等词与完整包含关系只提供建议，不自动认定加工方式；板框内的图形也不会因此被认作孔。可按图层设置，或勾选图形批量设置，单个图形设置优先。导入弹窗左侧固定显示 CAD，右侧独立滚动并默认展示待确认项；点击提示会高亮并放大对应图形。全部图形及板厚、材质分别查看，自动处理记录、模板与格式说明按需展开。单位缺失时直接展示单位输入，缺少参数时自动切换并聚焦对应字段。用户主动应用的模板低于手工设置，仅在浏览器本地保存图层配置，不保存文件 handle 或图纸。通过独立几何、加工归属与参数检查后，才生成导入项目。

预览画布中单击选择保持当前视野，双击图形或点击右侧查看入口定位放大；Shift 点选可跨图层增减选择。拖动平移，滚轮平移（Shift 横向）、Ctrl/⌘ + 滚轮围绕指针缩放，角落按钮和 + / − / 0 控制视野。选中后可直接更改用途或忽略，详细槽宽、槽深仍在右侧确认；用途切换及忽略后恢复保留既有加工参数。Esc 优先关闭用途菜单、取消拖动或选择，再关闭弹窗。原图和只读导入效果均可浏览；单位与模型空间收进右侧「图纸设置」，单位未知时展开要求填写。

首尾端点在物理 0.001 mm 内且归一后仍为有效区域时自动处理；唯一匹配的 LINE / ARC 链使用相同端点标准。保留原始路径、端点位移和处理记录，可查看叠图、恢复原路径或重新应用。实际断口、分支、自交不会自动闭合，原 DXF 不改写。

读取 `$INSUNITS` 并统一为 mm；单位未知必须选择原单位。同文件重读保留手工核对和已填写的毫米参数，换文件恢复声明单位并清空旧设置。内置示例采用明确标注的兼容预设；上传文件只有用户主动选定该预设时才采用旧命名约定，包括 `CUT_12MM` 板厚提示和按原单位换算的 `POCKET_DEPTH`。陌生图层的数字不推断为板厚或槽深。布局视口、尺寸和文字不成为加工路径；HATCH 多段线边界只有与已有路径匹配时视为填充，否则要求处理，避免遗漏仅由填充表达的几何。

三维/非平面或倾斜 OCS、仅拟合点样条、非正权重样条、超过 16 阶的样条、HATCH 边路径等暂不转换，会展示具体诊断。开放线可由用户定义为铣槽：选择中心路径并填写槽宽、槽深（mm），按圆头展开加工区域；或明确选择直线连接两端成区域，预览标出新增闭合边。原始路径、槽宽及画法随来源保留，模板保存批量映射，SVG 保留开放中心线。闭合环中心路径、多边界展开、分支、自交、重复或未确认的加工轮廓不能提交。单文件最多 2 MB，每实体最多 4096 个采样顶点、总计最多 50000 个，块实例最多 10000 个、嵌套最多 32 层；资源超限在转换前拒绝，不自动简化。

## 工作区与操作

首页保留统一的导入和示例入口。导入后的顶部左侧显示项目信息，中间固定切换「零件排版 / 成品组装」，右侧提供当前工作区操作、导出和更多；切换工作区时入口保持原位，窄屏简写为「排版 / 组装」。已有板材时保留「自动排版」作为排版设置的统一入口，只有零件时显示「安排用料」。无板材的项目直接展示可选择的零件图纸和图纸概览，编辑与单独导出无需先排版。选择/平移/磁吸/撤销独立放在板材画布底部工具栏；零件图纸提供撤销。点击选择零件后，下方工具栏出现「清角/T骨」按钮，直接打开该零件的编辑器。左侧固定资源栏含零件/板材、搜索、对应新增；右侧固定概览，选中零件时显示信息。窄屏显式切换资源/画布/信息，选择零件后保留画布以便继续使用底部工具栏。

右侧概览默认保留轮廓利用率、使用/库存板数和已放数量；板材行、指标详情可展开。选中零件时，96×124 px 预览与名称尺寸并排，锁定和旋转常驻，加工与来源、复制和删除按需展开。未导入状态居中显示简短引导。检查结果在底部常驻，异常在右侧突出并支持查看定位；候选出现时可切换概览/对比及当前/原图比较基准。

图标按钮通过统一 tooltip 展示用途、快捷键或禁用原因；文件名、零件/板材名称、来源和状态文字实际截断时可查看完整内容。折叠入口悬停或键盘聚焦可预览包含的信息，展开后关闭提示。

视觉采用米白纸底、钴蓝与朱橙双色印刷风格。欢迎页有网点木作插画、导入与示例入口；品牌及标题使用本地 Noto Serif SC 900 子集（附 SIL OFL 许可），英文与概览数字使用 Times New Roman，表单与图纸尺寸保留清楚的系统字体。选中零件以朱橙强调，孔槽与余料分别显示。

- V 选择；H 手形平移；滚轮平移，Shift 横向；Ctrl/⌘ + 滚轮围绕指针缩放，Ctrl/⌘ + 0 适应全部。
- 空白或板材背景短点击返回概览；超过 4 屏幕像素为平移，保留选择。Esc 优先关闭弹窗/取消画布拖动，再取消选择。Ctrl/⌘ + Z 撤销。
- 当前排版可拖动零件。蓝线表示 8 像素磁吸，Alt 暂停。松开后独立校验尺寸、板厚、材料、轮廓间距与边界，合法才提交一次历史。原图和候选只读。
- 新建矩形/圆形默认待放置，可选立即寻找合法位置。待放置零件可拖到板材，或在信息栏明确选择目标板材并点击放置；自动排版也包含所有待放置零件。复制保留真实外轮廓与孔槽，新副本待放置。
- 板材宽高 100–10000 mm、厚度 1–100 mm，材质可指定。仅当前没有零件的板可删除，非空板需先移走零件。板厚/材质修改同步当前该板上的零件，原图保持不变。
- 自动排版基于 SVGnest 的 NFP 轮廓放置和遗传搜索，同板厚、同材质零件可整体跨板重排，锁定零件作为固定障碍。旧局部优化器仅保留为测试对照。候选对比显示相对基准的“跨板调整”数量。
- 余料优先在用板数相同时，按板厚和材质分组扩大每组最大连续矩形余料；连续余料相同时，按库存顺序优先填充前面的板，再比较余料总量。三种模式共享 SVGnest 引擎，通过适应度区分目标。排版目标在自动排版设置中选择，当前模式在右侧概览和候选提示中显示。
- 「更多 → 恢复原图位置」说明影响范围后确认：恢复仍在库存中的原板位置，已删除原板上的零件保留当前位置，手动新增零件和板材保留，可撤销。

## 清角/T骨

导入后，先点击选择零件，再点击画布底部工具栏「清角/T骨」。编辑器打开先显示整个零件，点击图上的孔槽或右侧唯一的轮廓列表选择加工位置，自动放大所选轮廓；没有候选角点的轮廓也可以查看。预览支持滚轮围绕指针缩放、拖动平移，以及「整个零件」「放大所选」和加减缩放按钮。角点编号保持固定屏幕大小，移到刀口旁用细线标明位置；拖动不会误勾选角点。

右侧依次设置加工位置、刀具与样式、清角位置。刀具直径范围为 0.1–100 mm，支持狗骨 / T 骨；T 骨可沿相邻长边或短边清角。勾选角点控制加工，独立的「定位」按钮仅放大查看，不改变选择；图上编号与勾选框同步，切换轮廓保留该轮廓的勾选状态，调整参数不重置预览。手机定位后会回到图纸预览，取消与应用固定在底部。每次应用处理当前轮廓。工具识别可清角的几何位置，不自动判定装配用途；榫卯只是其中一种使用场景。

除了直角内角，还支持由两条相互垂直的直边及相切四分之一圆弧构成的普通圆角。应用时先恢复所选圆角的直角位置，再生成狗骨 / T 骨；未选圆角保持原样。相邻共线线段按完整直边判断空间，贴着零件边界的槽口不标为清角角点。圆形孔、半圆槽端、已有狗骨 / T 骨、椭圆弧和非直角曲线不会被当作普通直角圆角。

清角直接修改实际闭合轮廓，圆弧弦误差不超过 0.005 mm。应用写入一次可撤销事务，保留源图、槽深、材质、板厚和放置坐标，并清除旧排版候选。取消和预览不修改项目；刀具切到其他边、穿出零件、断开零件或与其他加工区域产生不支持的交叉时禁止应用。搜索中与原图 / 候选视图不能应用。

## 排版、指标与导出

SVGnest 是生产主引擎：NFP 求轮廓接触位置，遗传算法搜索放置顺序和旋转，跨板范围由真实库存、板厚和材质限定。使用上游种群 10、变异率 10，并增加独立排列和停滞重启；保留精英和已验证最佳布局，不保证全局最优。复杂凹轮廓保留实际形状，所有候选以原始轮廓独立校验。接入来源、许可与适配边界见 [开源引擎说明](docs/design/open-source-nesting.md)。

界面默认连续 50 轮没有改善时停止，可设置 1–1000 的整数。利用率模式看最高已验证利用率；加工模式看板数和预计空移；余料模式看板数、整块余料、前板填充和可用余料总量。当前目标改善后计数归零，每个材质/板厚组完成一代才计一轮，辅助几何排序不重置计数。利用率模式的候选先比较实际用板面积，面积相同再比较板数。概览显示真实 Efficiency 曲线和当前目标的未改善进度；连续未改善模式没有时间/总代数截止，也可手动停止并保留曲线。自动停止不代表全局最优。另可选择时间与代数限制（1–300 秒、每组 1–100 代，先到者停止）。NFP 缓存和各组种群跨代保留。“搜索详情”显示引擎、已完成代数、完整排列评估数、可行数、重启次数、轮廓配对计算与停止原因。只保留所有零件恰好一次、满足材料/板厚/锁定/间距/边界的完整方案；未找到更好结果时保留合法当前布局。取消搜索保留已接收的完整合法候选，只有「应用」写入当前布局；搜索期间「当前排版」按实际计算速度抽样展示一代内的最新完整可行试排，跳过缺件或不合格的尝试并保留上一套完整画面，整套快照之间有同步移动/旋转过渡，不设播放选项、不逐件回放；指标、检查和最终应用对应独立保留的最佳完整方案，原排版与撤销历史保留；零件/板材编辑、参数修改、导入、撤销、恢复和导出暂不可用，底部选择/平移/磁吸/撤销工具与 V/H 快捷键一起禁用，画布拖动与点选暂停；缩放、滚轮浏览、资源列表点选查看、原图对照与停止仍可使用。停止后恢复编辑，修改会清除候选，过期结果不能覆盖编辑。

允许编辑部分排版：待放置不是移动其他零件的阻碍。概览显示已放/总数与未放置问题；面积和通孔净面积仅计算已放置零件。轮廓利用率为已放外轮廓面积/当前布局板面积；净利用率扣除通孔，保留浅槽。布局板和库存面积分别展示；对比集合变化时明确提示，不能把新增/删除资源说成排版提升。

加工行程是最近邻访问零件中心的空移近似，不是 CNC 刀路。余料为避开膨胀轮廓包围盒的每板最大矩形，每轴最多 256 个坐标，可能保守低估凹轮廓自由空间。默认最小余料 100×100 mm、间距 3 mm、边距 6 mm，实际参数须按刀具确定。

SVG 可导出完整二维布局，或从零件信息单独导出当前零件图纸；无板材项目顶部的「导出」也进入零件导出。单独导出无需放置零件，毫米宽高与 viewBox 对应实际尺寸，并包含清角后的轮廓、通孔、槽深、板厚和材质。XML 文本转义、非有限坐标拒绝。待放置零件仍阻止完整布局导出。完整布局必须是合法排版，或保持完整导入几何/库存且所有位置/板材/角度逐件完全一致的源图；源图间距或槽深警告保留供核对例外，但绝不绕过缺件检查。新增资源使该例外失效。二维排版不提供刀具补偿、孔中放件、机床后处理或 CNC 程序生成；其轮廓检查与 3D 装配检查使用各自的检测依据。

## 3D 组装

导入或新增零件后，顶部「成品组装」进入组装工作区。用真实外轮廓与板厚建模，通孔保留空腔；浅槽需要逐槽确认正面（局部 +Z）或反面，再按实际槽深扣除材料。加工面未知或几何不完整时显示待确认，不能宣称已完成实体检测。

点击左侧未加入的零件即可放入场景并选中；在场景中也可直接点选或拖动零件，未选中时同样可以直接拖动。默认隐藏三轴控件，右侧只显示当前零件与推荐落位；需要数值时打开“精确调整”，检测依据在“检查与规则”中设置。直接拖动在当前 XY 平面移动，三轴控件和按需打开的数值可进一步调整高度与朝向。G 移动、R 旋转、V 选择；旋转控件默认 90° 步长，Alt 临时取消步长。相机在零件拖动期间暂停，空白处环绕观察，滚轮缩放；可切换前/侧/顶视、适应全部、定位所选、透视和爆炸查看。

- 红色只覆盖检测到的实际材料交叠区域，孔槽空腔及合法贴合不误报。透视查看可看到内部冲突。
- 选中零件后，黄色显示通过最终几何和适用配合规则检查的候选位置及半透明落位预览；灰色虚线表示尚待确认。槽配合需要指定插入边、插入深度和制造间隙。最终位置与完整安装路径分别检测。
