# 木作 / 板材工作台

浏览器内运行的二维木作 DXF 排版工作台。React 19、TypeScript、Vite、Zustand；真实示例为 3 张 1220 × 2440 mm 板材、53 个零件、28 个孔和 29 个槽。示例自动载入，孔槽与标注跟随真实轮廓的移动和旋转。

## 运行

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

开发地址为 http://127.0.0.1:4190。生产构建输出在 `dist/`。DXF 导入与排版分别运行在 Worker 内，文件不上传。界面字体网络不可用时采用本机中文字体。

## 图纸约定

仅支持声明毫米单位 `$INSUNITS=4` 的 ASCII DXF、世界 XY 平面的二维轮廓。板框使用 `REF_STOCK` 图层且必须是真实正交矩形；零件使用 `CUT_12MM` 等板厚图层；孔使用 `HOLE_12MM`；槽使用 `POCKET_DEPTH6` 等明确槽深图层。允许闭合 LWPOLYLINE / 二维 POLYLINE、圆以及闭合无分支 LINE / ARC 链，bulge 弧段按 0.025 mm 弦误差采样。HATCH 与文字不作为切割轮廓，P 数字文字关联零件编号。未闭合、自交、未知加工图层、缺失单位、三维/OCS、SPLINE 和无法唯一归属的孔槽均明确报错，不静默删除。单文件上限 2 MB；单实体最多 4096 个采样顶点、全图最多 50000 个，采样点分配前检查预算，不自动简化超限轮廓。

## 排版与指标

实际算法是轮廓锚点候选、多起点尝试和局部搬移的有限预算启发式；使用原图作为可行种子，检查多边形碰撞、轮廓间距、边界、材料/板厚和锁定约束。不是完整 NFP 求解，也不是遗传算法，不保证全局最优或预算内一定找到可行排版。搜索预算为约 5 秒和 60000 个候选，随后完整验证还有额外耗时。请求 24 次尝试可能只完成 1 次，界面显示真实完成次数，不显示虚构进度。

利用率按外轮廓面积除以当前排版板材总面积计算，不扣除孔槽。优化可将兼容零件集中到较少板材（例如 2 张减为 1 张），未使用板材仍保留在项目库存中；板材总面积不变时利用率不变。加工行程为最近邻访问零件中心的空移近似，不是 CNC 刀路。余料是避开膨胀零件包围盒的每板最大矩形，每轴最多 256 个坐标，任何与膨胀包围盒相交的网格单元都视为占用；坐标抽稀与凹轮廓包围盒均可能保守低估自由空间；默认只显示至少 100 × 100 mm 的矩形。默认间距 3 mm、边距 6 mm，实际间距须根据刀具确定。示例在改为 6 mm 间距时会出现真实间距问题。

## 操作

点击零件或使用左侧可键盘访问的清单选择；查看尺寸、通孔/槽深，锁定当前位置。Ctrl / ⌘ 加滚轮缩放，拖动图纸空白区域平移，适合全部板材按钮复位。选择原图/当前/候选比较，只有完整通过验证的候选可以应用；撤销精确恢复上一版，恢复原图也可撤销。任一设置、锁定、板厚或导入变更都会终止搜索并清除候选；取消搜索保留已接收且完整验证的最佳合法候选，不自动应用。修改板厚同步所属零件与板材元数据并清除撤销历史，槽深超出板厚会成为排版错误。锁定以当前排版作为搜索基线，不修改保存的原图坐标。

SVG 导出的是当前二维排版，使用 mm、包含编号、板厚/材料元数据与变换后的孔槽；用户文本按 XML 转义，拒绝非有限坐标。只有当前参数下通过全部验证的排版，或位置、板材和角度与导入原图逐件完全一致的排版可以导出；应用过移动方案后若修改间距、边距或板厚使其无效，导出会禁用并说明原因。原图即使在当前刀具设置下出现间距或槽深警告，也可导出供核对。没有 3D、刀具补偿、嵌套孔中放件、机床后处理或 CNC 程序生成。

### 全屏编辑工作区

右上角的浮动工具栏集中选择/平移、DXF 导入、矩形/圆形组件、板材管理、排版/取消、撤销、恢复原图、SVG 导出、数据分析和帮助。工具分为两排，统计或组件属性位于工具栏下方，与工具栏对齐。随附示例图纸入口位于导入弹窗。初次载入的当前排版与导入图纸坐标相同；「原始图纸」是独立、不可变的导入快照。左侧组件列表跟随工作库存，新增组件在原图视图选中时会切换到当前排版。

选择工具（V）可拖动当前排版中的组件，手形工具（H）平移画布。拖动过程只显示临时轮廓，松开后独立检查全体布局，合法才写入一次历史。锁定、板厚/材质不符、越界和间距冲突会拒绝修改；蓝色对齐线对应默认开启的 8 屏幕像素弱磁吸，Alt 临时关闭。滚轮平移、Shift 横向平移、Ctrl/⌘ + 滚轮围绕指针缩放、Ctrl/⌘ + 0 适应全部、Ctrl/⌘ + Z 撤销；文本输入时不会占用这些快捷键。

新建组件只支持真实矩形和圆形；圆轮廓采样弦高误差不超过 0.1 mm。自动初始放置采用每板最多 24×24 个有界候选锚点，在同厚板材寻找符合板边和间距的位置；只重新检查可能相交或违反间距的邻近轮廓。它可能错过可行位置，失败会保留项目并提示先加板或调整参数。新增板材宽高范围 100–10000 mm，厚度 1–100 mm，材质沿用同板厚板材。

历史保存工作模型及排版，支持撤销新增组件、新增板材、移动、旋转和应用排版。修改板厚仍清空历史；板厚修改作用于当前分配到该板的组件。「恢复原图」只恢复仍在库存中的导入组件原板位置，并恢复全部工作板材可见，保留新建组件及其当前位置；原板已删除的组件保留当前位置并提示，该操作可撤销。它不承诺满足当前刀具间距。候选在手动修改后失效，过期 Worker 结果不能覆盖编辑。

SVG 导出只使用当前排版。导入原始几何/库存且坐标完全恢复时保留旧版「供核对」导出例外（可保留人工修订厚度）；一旦含新增组件或新增板材，该例外失效，必须满足当前布局验证。SVG 含毫米尺寸、板厚、材质、孔轮廓和槽深元数据，不是 CNC 刀路。

数据分析默认显示在右侧，与选中组件属性互斥；关闭属性会恢复分析，工具栏「数据」可折叠/打开。整体指标和每板数据随原图/当前/候选视图更新，净利用率扣除真实通孔面积而不扣浅槽，表格对比三个视图的真实指标。布局板面积与工作库存面积分开列出，紧凑方案不会移除库存板。原图统计使用不可变导入快照。加工空移和矩形余料仍采用上述有限预算保守估算。

板材管理显示当前组件数；只有当前没有组件的板材可删除，非空板需先移走组件。删除后弹窗保持打开，可点击弹窗内「撤销」恢复整个工作模型及排版；删除终止搜索并清空候选。原图有组件但当前已空的板材也可删除，相关组件的工作材质关联和工作基线改为当前板材，导入快照保持不变。没有组件时可删除最后一张板材，空态可新增板材。
