# 木作 / 板材工作台

浏览器内运行的二维木作 DXF 排版工作台。React 19、TypeScript、Vite、Zustand。默认空工作区；「更多 → 打开示例图纸」预览真实 3 张 1220 × 2440 mm 板材、53 个零件、28 个孔和 29 个槽。示例也需确认材质后导入。

## 运行

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

开发地址 http://127.0.0.1:4190，生产输出 `dist/`。导入与排版分别运行在 Worker 中，DXF 文件不会上传。工作仅保存在本页内存；刷新会丢失，暂无持久化后端。

## 双导入与源图

左侧「导入 DXF」选择整板图纸或零件轮廓。文件先进入独立预览；取消、解析错误和单位修改不更改工作项目、历史、候选或正在运行的搜索。确认才执行一个可撤销事务。已有项目明确选择追加或打开新项目；打开新项目也可撤销恢复上一项目。

- **整板图纸**：可含多张正交矩形板框。优先使用 `REF_STOCK`；默认图层上明确包围零件的最外层矩形也可识别为板框。不能明确识别时要求修正图层。预览中逐板确认厚度和材质；保留原有坐标。
- **零件轮廓**：无需板框。默认图层 `0` 或 `CUT` 表示闭合外轮廓，`HOLE` 表示通孔，`POCKET_DEPTH3` 表示深度 3 的槽。独立输入板厚、材质和每种轮廓的数量（1–100，总计最多 1000 个），确认后加入待放置；不会虚构库存或改动已有排版。内部普通 CUT 轮廓不会自动变成孔，必须明确加工语义。可用 `/standalone-parts.dxf` 测试：200×100 mm 带直径 25 mm 孔及深 3 mm 槽，另一个 120×80 mm 零件。

追加是纯合并事务，对新板材、零件和全部放置引用统一重新映射 ID，避免重复导入冲突。原图是各导入来源的组合，另保留各文件几何快照；独立零件在原图中仍待放置。工作项目的材质和来源记录在零件自身，删除板材不会抹去身份。手动新增/复制/删除、材质/板厚、锁定、移动、旋转、导入、应用与恢复均可撤销，历史包括源图基线。

## DXF 约定与边界

支持 ASCII DXF、世界 XY 平面的二维闭合 LWPOLYLINE / POLYLINE、圆以及无分支闭合 LINE / ARC 链。bulge 弧段按 0.025 mm 弦误差采样。读取 `$INSUNITS` 的常用长度单位，并转换为 mm；单位缺失或未知必须选择原单位（毫米、厘米、米、英寸或英尺）。`CUT_12MM` 等厚度后缀为毫米，`POCKET_DEPTH` 的数值遵循图纸单位；最后板厚由预览确认。

HATCH 和普通文字为显示注释，不作切割路径；整板的 P 数字文字用于编号。开放、自交、未知加工图层、内部语义不明确、无法唯一归属的孔槽、三维/OCS、SPLINE 均报错，修正后重试，不静默删除轮廓。单文件最多 2 MB，每实体最多 4096 个采样顶点、总计最多 50000 个；采样前检查预算，不自动简化。

## 工作区与操作

桌面顶部 42 px：项目身份、当前优化模式、自动排版/导出/更多；点击模式文字可调整设置。选择/平移/磁吸/撤销独立放在画布底部工具栏。左侧固定资源栏含零件/板材、搜索、对应新增；右侧固定概览，选中零件时显示信息，选择不会改变画布尺寸。窄屏显式切换资源/画布/信息。

右侧概览默认保留轮廓利用率、使用/库存板数和已放数量；板材行、指标详情可展开。选中零件时，96×124 px 预览与名称尺寸并排，锁定和旋转常驻，加工与来源、复制和删除按需展开。未导入状态居中显示简短引导。检查结果在底部常驻，异常在右侧突出并支持查看定位；候选出现时可切换概览/对比及当前/原图比较基准。

图标按钮通过统一 tooltip 展示用途、快捷键或禁用原因；文件名、零件/板材名称、来源和状态文字实际截断时可查看完整内容。折叠入口悬停或键盘聚焦可预览包含的信息，展开后关闭提示。

视觉采用米白纸底、钴蓝与朱橙双色印刷风格。欢迎页有网点木作插画、导入与示例入口；品牌及标题使用本地 Noto Serif SC 900 子集（附 SIL OFL 许可），英文与概览数字使用 Times New Roman，表单与图纸尺寸保留清楚的系统字体。选中零件以朱橙强调，孔槽与余料分别显示。

- V 选择；H 手形平移；滚轮平移，Shift 横向；Ctrl/⌘ + 滚轮围绕指针缩放，Ctrl/⌘ + 0 适应全部。
- 空白或板材背景短点击返回概览；超过 4 屏幕像素为平移，保留选择。Esc 优先关闭弹窗/取消画布拖动，再取消选择。Ctrl/⌘ + Z 撤销。
- 当前排版可拖动零件。蓝线表示 8 像素磁吸，Alt 暂停。松开后独立校验尺寸、板厚、材料、轮廓间距与边界，合法才提交一次历史。原图和候选只读。
- 新建矩形/圆形默认待放置，可选立即寻找合法位置。待放置零件可拖到板材，或在信息栏明确选择目标板材并点击放置；自动排版也包含所有待放置零件。复制保留真实外轮廓与孔槽，新副本待放置。
- 板材宽高 100–10000 mm、厚度 1–100 mm，材质可指定。仅当前没有零件的板可删除，非空板需先移走零件。板厚/材质修改同步当前该板上的零件，原图保持不变。
- 自动排版基于 SVGnest 的 NFP 轮廓放置和遗传搜索，同板厚、同材质零件可整体跨板重排，锁定零件作为固定障碍。旧局部优化器仅保留为测试对照。候选对比显示相对基准的“跨板调整”数量。
- 余料优先在用板数相同时，按板厚和材质分组扩大每组最大连续矩形余料；连续余料相同时，按库存顺序优先填充前面的板，再比较余料总量。三种模式共享 SVGnest 引擎，通过适应度区分目标。模式名称在顶栏、右侧概览和候选提示中持续显示。
- 「更多 → 恢复原图位置」说明影响范围后确认：恢复仍在库存中的原板位置，已删除原板上的零件保留当前位置，手动新增零件和板材保留，可撤销。

## 排版、指标与导出

SVGnest 是生产主引擎：NFP 求轮廓接触位置，遗传算法搜索放置顺序和旋转，跨板范围由真实库存、板厚和材质限定。使用上游种群 10、变异率 10，并增加独立排列和停滞重启；保留精英和已验证最佳布局，不保证全局最优。复杂凹轮廓保留实际形状，所有候选以原始轮廓独立校验。接入来源、许可与适配边界见 [开源引擎说明](docs/design/open-source-nesting.md)。

界面默认按最高已验证利用率的平台期停止：耐心代数 50，可设置 100 或其他 1–1000 的整数。每个材质/板厚组完成一代才计一次耐心；连续 N 代利用率未提高就停止，提高后归零。余料形状改善不重置计数。排版概览和设置中显示实时 Efficiency 曲线；耐心模式没有时间/总代数截止，也可手动停止并保留曲线。平台期停止不代表全局最优。另可选择时间与代数限制（1–300 秒、每组 1–100 代，先到者停止）。NFP 缓存和各组种群跨代保留。“搜索详情”显示引擎、已完成代数、完整排列评估数、可行数、重启次数、轮廓配对计算与停止原因。只保留所有零件恰好一次、满足材料/板厚/锁定/间距/边界的完整方案；未找到更好结果时保留合法当前布局。取消搜索保留已接收的完整合法候选，只有「应用」写入当前布局；设置/编辑/确认导入会终止搜索并清除候选，过期结果不能覆盖编辑。

允许编辑部分排版：待放置不是移动其他零件的阻碍。概览显示已放/总数与未放置问题；面积和通孔净面积仅计算已放置零件。轮廓利用率为已放外轮廓面积/当前布局板面积；净利用率扣除通孔，保留浅槽。布局板和库存面积分别展示；对比集合变化时明确提示，不能把新增/删除资源说成排版提升。

加工行程是最近邻访问零件中心的空移近似，不是 CNC 刀路。余料为避开膨胀轮廓包围盒的每板最大矩形，每轴最多 256 个坐标，可能保守低估凹轮廓自由空间。默认最小余料 100×100 mm、间距 3 mm、边距 6 mm，实际参数须按刀具确定。

SVG 导出当前完整二维布局，单位 mm，含变换后的外轮廓、通孔、槽深、板厚和材质；XML 文本转义、非有限坐标拒绝。待放置零件阻止导出。只有完整合法排版，或保持完整导入几何/库存且所有位置/板材/角度逐件完全一致的源图才可导出；源图间距或槽深警告保留供核对例外，但绝不绕过缺件检查。新增资源使该例外失效。没有 3D、刀具补偿、孔中放件、机床后处理或 CNC 程序生成；轮廓检查不等同于家具装配验证。
