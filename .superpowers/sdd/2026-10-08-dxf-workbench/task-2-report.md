# Task 2 report

Implemented optimizer and Worker protocol in the three requested files; additionally updated geometry.ts and geometry.test.ts with parent-authorized independent material and pocket-depth checks.

Search validates the CURRENT source before admitting it. It retains complete feasible source layouts, then locally relocates unlocked pieces and attempts independent size/shape-prioritized restarts. Candidate anchors include board edges, bounding-box adjacency and sampled contour vertex contacts. Collision checks use actual external sampled contours after a bounding-box distance prune. Rotated contours are cached and equivalent sampled orientations deduplicated. Details stay on Part records and are transformed exclusively by Placement; no parts are dropped and no stock added. Material is derived from part.stockId's source stock. Locked placements retain their original coordinates/rotation/sheet/flag. Every accepted complete candidate passes validateLayout independently.

Ranking: utilization minimizes occupied sheet count then sum of occupied anchored extents; machining minimizes sheet count then nearest-neighbor center rapid-distance estimate; remnant minimizes sheet count then maximizes total qualifying largest free rectangle area, followed by extent/travel. Different row/column anchors accompany machining mode. Remnant minimum width always refers to sheet X and height to sheet Y (no automatic minimum rotation), consistently with measureLayout.

Budget: maximum 100 requested integer attempts (fractional iteration settings are floored), 60,000 candidate checks, or 5 seconds inside search loops. Initial/final validation and measurement are synchronous and can add overhead for pathological geometry; the cap is a practical search cap, not an absolute latency guarantee. Source validation and baseline measurement happen even with zero attempts. Progress reports completed attempts and current legal incumbent metrics. Worker cancellation is external terminate(); progress/done/error messages are tested. No UI changes.

Tests were written and executed before implementation: initial failure was missing nesting module. Subsequent meaningful cases cover compaction 2→1 stocks, complete placements, lock preservation, required rotation, impossible dimensions/thickness, nonfinite/unknown settings, illegal source gap, all modes, concave interlocking, material grouping, remnant improvement, immutability, progress and bounded real sample search; Worker protocol is exercised using a mocked Worker global. Independent validator regressions cover material and null/NaN/Infinity/excessive pocket depths after thickness edits.

Verification: pnpm test tests/nesting.test.ts tests/geometry.test.ts tests/dxf.test.ts: 34 tests passed. pnpm exec tsc --noEmit: passed.

Real public/sample.dxf: 53 parts, 3 available sheets, gap3/margin6 complete legal result. One iteration took ~2.98 seconds. It moved 8 parts with travel 19,500.26→18,199.62 and qualifying reusable area 263,409.48→272,712 mm²; utilization stayed 85.42%, no sheet reduction. Gap6/margin6 rejects original and returned null after ~3.90 seconds; that is a search failure, not proof of impossibility. All returned layouts were independently validated.

24-requested-iteration sample runs reached candidate budget during first attempt and produced distinct valid complete layouts: utilization ~2.82s, travel18,199.62/remnant272,712; machining ~2.56s, travel18,219.28/remnant269,088; remnant ~3.15s, travel19,442.60/remnant263,409.48. The remnant run retained source reusable area (honest unchanged objective; travel tie-break improved). Values use minimum remnant10×10mm for repeatable test coverage; product defaults may differ.

Limitations: finite deterministic heuristic, no global-optimal claim; greedy restarts can fail dense imports while local validated seed remains useful. Contour contacts sample up to20 nearby contours and12 vertices each, so not a complete NFP search. Remnant rectangles conservatively exclude expanded bounding boxes and use one largest qualifying rectangle per sheet. Travel is an estimate between centers, not CNC toolpath time. Candidate cap can stop well before requested attempts, reported accurately. Public Worker protocol assumes serial start messages; UI must terminate and create a fresh Worker to cancel a synchronous run.
